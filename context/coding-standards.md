# Coding Standards

## TypeScript

- Strict mode (TS 6 default, keep it on). `noUnusedLocals`, `noUnusedParameters`, `erasableSyntaxOnly`, `verbatimModuleSyntax` are set in `tsconfig.app.json`
- `verbatimModuleSyntax`: use `import type` for type-only imports
- `erasableSyntaxOnly`: no `enum`, `namespace` or constructor parameter properties. Use union types / `as const` objects
- No `any` types. Use proper typing or `unknown` and narrow
- Define types for props, API requests/responses and data models. Derive types from Zod schemas (`z.infer`) where a schema exists
- Use type inference where obvious, explicit types where helpful

## Boundaries

- Validate external input with Zod: API responses, URL params and query strings, forms, `import.meta.env`
- Forms: react-hook-form with `zodResolver` from `@hookform/resolvers/zod`
- Server state goes through TanStack Query (queries/mutations), not `useEffect` + `useState`. Keep fetch functions and query keys outside components
- Map API errors to user-facing messages in ONE place. Never show raw error objects or stack traces

## Data

- Paginate lists that can grow
- Money as integer minor units (cents), formatted only for display

## Security

- This is client code: everything in the bundle, `VITE_*` env vars included, is public. No secrets in the frontend
- Never render untrusted HTML (`dangerouslySetInnerHTML`) without sanitizing

## React

- Functional components and hooks. One job per component
- Handle loading, empty and error states
- Use MUI components and the theme (`sx`, `styled`) for styling. Check the MUI v9 API, not older versions

## File Organization

Current layout (Vite scaffold):

- `src/main.tsx`: entry, renders `<App />`
- `src/App.tsx`: root component (scaffold demo content)
- `src/assets/`: imported static assets
- `public/`: static files served as-is, including `mockServiceWorker.js` (generated by MSW, do not edit)

## Naming

- Components: PascalCase, file named after the component (`UserCard.tsx`)
- Functions and hooks: camelCase, hooks prefixed with `use`
- Constants: SCREAMING_SNAKE_CASE
- Types/Interfaces: PascalCase (no prefix)

## Code Quality

- No commented-out code unless specified
- No unused imports or variables
- Keep functions under 50 lines when possible
- `npm run lint` passes (react-hooks and react-refresh rules are on)
